Política de Privacidad

Última actualización: 14 de octubre de 2026

Esta Política de Privacidad explica cómo se recopila, utiliza y protege la información cuando utilizas esta aplicación de realidad virtual para Meta Quest.

1. Responsable del tratamiento

Responsable: JDLB
Contacto: jdlozar@gmail.com

2. Datos que podemos recibir de Meta Horizon

  • Identificador de usuario de Meta Horizon.
  • Nombre de usuario o nombre visible del perfil.
  • Información básica del perfil.
  • Información necesaria para funciones de amigos.
  • Información relacionada con invitaciones.
  • Información asociada a Group Presence.
  • Identificadores de lobby o sesión.
  • Información de deep linking necesaria para unirse a sesiones multijugador.

La aplicación no solicita ni almacena la contraseña de la cuenta de Meta.

3. Finalidad del uso de los datos

  • Identificar al usuario dentro de la aplicación.
  • Mostrar el nombre o perfil del jugador cuando corresponda.
  • Proporcionar funcionalidades multijugador.
  • Crear y unirse a sesiones de juego.
  • Invitar a otros usuarios a una partida.
  • Permitir que un usuario se una mediante invitaciones o deep links.
  • Mantener Group Presence y funciones sociales relacionadas.

4. Multijugador y servicios de red

La aplicación utiliza Photon Fusion / Photon para proporcionar funcionalidades de red y multijugador. Photon puede procesar información técnica necesaria para establecer y mantener las conexiones de red, como identificadores de sesión e información de conexión.

Salvo que se indique expresamente lo contrario, la aplicación no envía a Photon más información del perfil de Meta Horizon de la necesaria para proporcionar las funciones multijugador.

5. Compartición de datos

No vendemos datos personales.

No compartimos datos de Meta Horizon con terceros para publicidad, elaboración de perfiles comerciales o venta de información personal.

Los datos podrán ser procesados por proveedores técnicos únicamente cuando sea necesario para operar la aplicación y sus funciones multijugador.

También podremos divulgar información cuando sea legalmente obligatorio hacerlo en respuesta a una solicitud válida de una autoridad competente.

6. Conservación de datos

Conservamos los datos únicamente durante el tiempo necesario para proporcionar las funcionalidades descritas en esta política o para cumplir obligaciones legales.

Los identificadores de sesión, invitaciones y otra información temporal relacionada con partidas multijugador pueden conservarse únicamente durante la duración de la sesión o durante el tiempo técnicamente necesario para su funcionamiento.

7. Seguridad

Adoptamos medidas razonables para proteger la información frente a accesos no autorizados, pérdida, uso indebido o divulgación.

8. Datos de menores

La aplicación está destinada a usuarios que cumplan la edad mínima indicada para la aplicación en Meta Horizon. Si en el futuro cambia la categoría de edad o se ofrecen funciones específicas para menores, esta política será actualizada.

9. Derechos del usuario y eliminación de datos

Dependiendo de tu país de residencia, puedes tener derechos relacionados con tus datos personales, incluyendo acceso, rectificación, eliminación, limitación del tratamiento u oposición.

Para solicitar acceso o eliminación de los datos que esta aplicación pueda haber recopilado o almacenado, contacta con: jdlozar@gmail.com.

10. Datos gestionados por Meta

Parte de la información utilizada por la aplicación es proporcionada y gestionada directamente por Meta Platforms a través de Meta Horizon. El tratamiento realizado por Meta está sujeto a sus propias políticas y condiciones de privacidad.

11. Cambios en esta Política de Privacidad

Esta Política de Privacidad puede actualizarse cuando se añadan nuevas funcionalidades, cambien los servicios utilizados o sea necesario por requisitos legales o de plataforma.
